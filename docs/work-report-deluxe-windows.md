# Deluxe Windows — отчёт по выполненным работам

Кратко: что сделано и зачем.

## 1. SEO и структура сайта

| Что | Зачем |
|-----|--------|
| Разбор «лишних» ссылок (Website Auditor: desktop + mobile меню) | Понять, это реальная проблема индексации или ложное срабатывание аудитора |
| Рекомендации по noindex / упрощению меню | Снизить дубли и шум в crawl budget без поломки навигации |
| Проверка LocalBusiness / areaServed / адреса в микроразметке | Корректные сигналы для локального SEO |
| Проверка/правки `llms.txt` | Чтобы AI-поисковики корректно считывали сайт |
| FAQ + page-metadata для service areas (66 городов без datasets, включая draft) | FAQ на страницах городов для SEO; контент готов и к публикации draft |
| Вопросы FAQ выровнены под People Also Ask (Apify SERP) | Отвечать на реальные поисковые вопросы, а не на выдуманные |

## 7. RingCentral (журнал звонков)

| Что | Зачем |
|-----|--------|
| Синк inbound/outbound в `ringcentral_calls` | Журнал реальных звонков компании |
| Checkpoint «с прошлого синка → сейчас» (фикс timezone UTC) | Не терять звонки и не синкать пустое окно «сейчас→сейчас» |
| Несколько номеров (основной + extra phones в Promotions) | Мониторить все рабочие линии |
| Exclude/restore внешних номеров | Чистить шум (спам/служебные) |
| Сверка phone clicks ↔ RingCentral | Понять, был ли реальный звонок после клика на сайте |
| Кнопки Sync / Check now в админке | Ручной контроль без ожидания крона |

---

## 8. Контент и деплой

| Что | Зачем |
|-----|--------|
| Export/import datasets **без** Promotions/телефонов/цен | Чтобы выгрузка контента не затирала настройки акций на проде |
| Понятные ошибки прав на запись `webflow-data` | Быстрее чинить Permission denied на сервере |
| Performance: LCP homepage, lazy-load карты Previous Jobs | Быстрее первый экран, меньше блокировок |

## Итог по смыслу

Сайт стал лучше для **SEO и локального поиска**, стабильнее для **лидов/рекламы**, прозрачнее для **продаж** (почта, контакты, звонки RingCentral) и безопаснее при **переносе контента** между средами.

### На проде проверить / доделать
- Права на `webflow-data` / `database/data` (chown под PHP-user)
- Миграции RingCentral / extra phones, env `RINGCENTRAL_*`
- Ротация Apify-токена (был в чате)
- При необходимости: PAA-FAQ для 32 «ручных» городов (сейчас обновлены 66 сгенерированных)
